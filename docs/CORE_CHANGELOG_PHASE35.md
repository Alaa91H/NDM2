# Phase 3.5 — سجل تغيير Core الأدنى

## التغيير الوحيد

**الملف:** `src-tauri/src/daemon/routes/common.rs`  
**الدالة:** `hidden_output_timed`

أضيف ربط صريح لـ`stdout` و`stderr` عبر `Stdio::piped()` قبل تشغيل العملية المؤقتة. كانت الدالة تستدعي `Child::wait_with_output()` بعد انتهاء العملية، لكن لم تكن قد طلبت من `Command` حفظ المخرجات. أدى ذلك إلى أن probe الخاص بـyt-dlp يتلقى stdout فارغًا رغم نجاح `yt-dlp` نفسه، فتفشل قراءة JSON برسالة EOF.

## سبب استحقاق الاستثناء

كانت قدرة الوسائط موجودة بالفعل في Core، كما كانت أدوات `yt-dlp` وFFmpeg موجودة وتنجح عند التشغيل المباشر. لم يكن NDM2 قادرًا على استهلاك الاستجابة بسبب فقدان stdout في مسار Core ذي المهلة. لا يمكن تصحيح ذلك من العميل من دون نسخ أو إعادة تنفيذ yt-dlp، وهو أمر محظور في نطاق المشروع.

## ما لم يتغير

لم يتغير محرك التنزيل، أو libcurl، أو Scheduler، أو Queue، أو Rules، أو failover، أو مصادقة bearer، أو تقييد loopback، أو مخطط API. ويدخل تغيير stdout/stderr في الدالة الموجودة فقط، ثم أثبت probe وتنزيل وسائط حقيقيان السلوك المصحح.

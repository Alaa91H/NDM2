# تقرير التحقق النهائي — NOVA Download Manager

**الإصدار المبني:** `2.2.1-alpha`  
**فرع العمل:** `fix/verified-transfer-progress`  
**تاريخ التحقق:** 17 أغسطس 2026  
**حالة النسخة:** اجتازت بوابات المصدر والاختبارات وحزم Linux العملية الموضحة أدناه.

## الملخص التنفيذي

أُجري تدقيق ثابت وعملي شامل للمشروع، ثم عولجت العيوب التي أمكن إثباتها قبل التعديل. أهم إصلاح وظيفي هو إزالة مسار حلقة مقبس libcurl غير الموثوق الذي كان يعلق نقل HTTP المحلي، وتوحيد النقل على محرك libcurl المتعدد المدعوم. أُثبتت نتيجة الإصلاح بتنزيلات خوادم محلية فعلية، منها المحتوى معروف الحجم، والمحتوى المتدفق مجهول الحجم، والتنزيل المجزأ المتكيف، وصفحات HTML الوسيطة وروابط التحويل والبدائل المعطلة.

كما أُصلح تلف واسع في ترجمات امتداد المتصفح البنغالية والفارسية والتايلاندية. استُخرجت كل المفاتيح من المصدر الإنجليزي المرجعي، وأُعيدت ترجمتها وفق تحقق بنيوي لا يسمح بفقد مفتاح أو تغيير موضع مثل `{count}` و`{title}`، ثم مُنع إدخال محرف الاستبدال `U+FFFD`. ونُظفت أيضًا مواضع نصية مرئية في واجهة التطبيق كانت تعرض محارف تلف بدل فواصل أو مؤشرات حالة صالحة.

> **تعريف معيار القبول:** لا يُعتبر مسار التنزيل ناجحًا بمجرد إنهاء دالة أو تغيير حالة المهمة، بل فقط عند إثبات اكتمال محتوى الملف، ورصد تقدم وسيط صادق، واختبار الواجهة التي تعرض هذا التقدم.

## اختبار القبول العملي للتنزيل والتقدم

اختُبرت النواة عبر خادم HTTP محلي متحكم به، وليس بمحاكاة واجهة أو استدعاء وهمي. الحالات الناجحة هي:

| الحالة | ما أثبته الاختبار |
|---|---|
| تنزيل جديد معروف الحجم | خروج محتوى كامل مطابق مع وجود تحديث تقدم وسيط قبل الوصول إلى 100%. |
| حجم غير معروف ثم يتضح من الترويسة | انتقال صادق من غير محدد إلى إجمالي معروف وتقدم حي. |
| استجابة chunked بلا `Content-Length` | عدم اختلاق نسبة خاطئة أو القفز من صفر إلى مكتمل. |
| تنزيل مجزأ متكيف | نمو التجزئة ودمجها لإنتاج ملف مكتمل. |
| صفحة HTML وسيطة | استخراج رابط الملف الفعلي وتنزيله. |
| بديل أول متعطل | تجاهل البديل الفاشل والانتقال إلى بديل صحيح. |
| SourceForge/GitHub وMeta Refresh | متابعة نمط الرابط الوسيط أو إعادة التوجيه إلى الملف الحقيقي. |
| واجهة التقدم | عرض نسبة فعلية، وانتقال متحرك من sweep غير المحدد إلى قيمة عددية، وعدم إعلان قيمة صفر كقيمة نهائية. |

## قيود منصة معلنة

تم بناء حزم Linux والتحقق منها على Linux x86_64. لا يجوز تعميم هذه النتيجة تلقائيًا على Windows أو macOS؛ إذ يلزم بناء واختبار المثبتات في بيئات تلك المنصات قبل إصدار متعدد المنصات. كما أن اختبار واجهة رسومية حقيقية يتطلب جلسة سطح مكتب تفاعلية، في حين أثبتت هذه الدورة سلوك النواة واختبارات الواجهة الآلية وحزم Linux القابلة للفحص.
